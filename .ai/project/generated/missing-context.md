# Missing Context

Perguntas que o agente deve fazer apenas se não conseguir inferir do repositório:

1. Qual é o nome oficial do projeto e, se existir, o codinome interno?
2. Quem são os usuários principais e qual problema central este produto resolve?
3. Quais são os objetivos de negócio e como o sucesso será medido?
4. Há metas explícitas de performance, segurança, confiabilidade, acessibilidade ou observabilidade?
